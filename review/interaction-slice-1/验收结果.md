# Interaction Slice 1 验收记录

- V1.0 对照：v1.0/（实现前原始 HTML、CSS、JS）。
- 默认 CV；固定 CV → Portfolio → Demo；两端停止。
- 切换 640ms，轻微弹性曲线；回弹 550ms。
- 鼠标和触摸跟手，距离阈值 min(100px, 文件夹宽度 × 18%)；短促拖动可通过速度 >0.5px/ms 提交。
- 滚轮阈值 80px；动画锁及 220ms 滚动静默重置，连续惯性事件只提交一次。
- 背景轻微视差，结束后回到原位。
- prefers-reduced-motion：立即切换，无入场/出场动画。
- 无点击路由、悬停抽纸或内页交互。

实际浏览器验证：Chrome；1440×900、1920×1080、390×844。移动端使用 Chrome 触摸事件模拟，并非实体手机测试。触控板以水平 wheel 事件模拟。

测试通过：键盘、动画锁、滚轮阈值、连续滚动、水平滚动、鼠标双向拖动、短距离回弹、速度提交、边界回弹、移动端左右触摸、纵向手势不切换、减少动态模式。无页面错误、无横向溢出。

三个视口初始 CV，以及从 Portfolio / Demo 切回 CV 的截图，均与 V1.0 逐像素相同。鼠标和触摸操作后回到 CV 亦一致。

类型检查：TypeScript --allowJs --checkJs --noEmit --target ES2022 --module ES2022 --lib DOM,DOM.Iterable,ES2022 dist/app.js，通过。
构建：node build.mjs，通过。本项目为 buildless HTML/JS；构建校验脚本语法和资源引用，输出三个静态文件至 build/。没有引入框架或修改部署配置。
