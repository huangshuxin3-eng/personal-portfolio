## 接入方式

hand-guide.js 独立于 app.js，不读取或写入 Carousel 的当前索引。前景位于 stationery 内，沿用该画布 overflow:hidden，由底边自然裁切，整个手部 pointer-events:none、aria-hidden=true。

尺寸公式不变：handWidth = 主文件夹容器实际宽 × 388/460 × .95 × 480/464；高度按 620/480。Desktop 底部偏移 -40% 手高，Mobile -22% 手高；旋转支点 50% 90%。参考 1.18 秒姿势的屏幕内可见宽比例继续沿用已验收 Desktop 约 91%、Mobile 约 90% 基准。

一次播放共 3400ms：进入、右移及短暂停顿、快速左擦与回收、第二次示范、下沉并淡出。+15° 最大右倾姿势位于 1350ms。最大姿势截图保留正式首页信息文字。

播放期间只调整绘制层级，让编号、说明、引导文字及页脚位于手部之上；现有小手 SVG 暂时隐藏并保留占位。退出或取消时移除临时 class，完全恢复原来的层级与小手，不移动原有元素。

用户第一次在文件夹上 pointerdown，或使用普通滚轮/触控板、左右方向键时，立即取消大手。监听器仅观察，不阻止默认行为，不停止事件传播，不控制文件夹切换。Ctrl+wheel 保留缩放行为。一次取消后，在同一次页面加载中不会重新开始引导；重新加载页面会重新展示一次。

## reduced-motion

正式首页减少动态模式沿用已验收 Step 2 的 1.18 秒、+14° 静态大手姿势，不自动运动。首次主动输入将静态大手移除，恢复原来的小手提示。Carousel 原有即时切换回退不变。运行中打开减少动态选项会立刻取消动画并显示这一静态姿势；之后不自动重播。

Desktop 和 Mobile 均保留原静态大手比例与裁切；调整视口时按相同公式重测。

## 验证结果

真实 Chrome 测试与图像检查，供用户随后人工验收。录屏通过浏览器录制接口生成，输入由鼠标、键盘及 CDP 触控操作驱动，不是渲染合成视频。

- 1440×900、1920×1080、390×844：12 个动作关键时刻无横向 overflow。
- 三种视口：自动引导完整退出后，CV 与 checkpoint 逐像素一致。
- 三种视口：CV → Portfolio → Demo → CV，最终 CV 与 checkpoint 逐像素一致；边界不循环。
- 鼠标拖动、移动触控滑动、点击、左右方向键工作；主动操作立即取消手部。
- 小滚轮输入仍不触发文件夹切换；持续滚动一次只前进一项；横向触控板 delta 可切换。
- Desktop/Mobile reduced-motion：没有自动或切换动画，已验收静态大手姿势可见；首次操作移除。
- 运行中切换 reduced-motion：立即停止运动并切为已验收静态姿势。
- 各视口零 JavaScript 错误。
- TypeScript allowJs/checkJs 检查通过；node build.mjs 构建通过，六个静态资源均验证并复制。
